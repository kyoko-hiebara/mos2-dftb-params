# 2026-09-02 セッション: 手法改善と skf_v5 (mac 完結)

## 動機 (朝の診断で判明した問題)
1. **Sb の絶対準位が未拘束**: バルク Sb の損失が E_F 整列だったため onsite の共通シフトが +0.065 Ha に流れ、
   DFTB のバルク Sb E_F = −1.45 eV (期待 ≈ −4.6 eV)。MoS2 v3 の VBM/CBM = −5.34/−3.47 eV と組むと
   Sb の E_F が MoS2 CBM より ~2 eV 上に来て、コンタクト計算が物理的に無意味になる。
   Mo/S のシフトも全て正 (+0.6〜1.6 eV) で共通成分は未拘束。
2. **有効質量が重すぎる** (K 点 VB −0.60 vs DFTB −1.00 m_e、CB +0.49 vs +0.73)、v3 では Q 谷も 0.43 eV (LAK 0.24)。
   バンド RMS 損失は曲率に鈍感。
3. optm1 で Mo_sh4d (上限 0.06)、S_e3d (上限 0.80 Ha)、opto2 の O_r2s (上限 5.0) が境界張り付き。
4. 反発フィットが 20 構造のエネルギーのみ (力データ未使用)。
5. Mo–Sb / S–Sb ペアと Sb 反発が未検証・未整備。

## 今日やったこと (すべて mac)
- **真空準位基準の整列ターゲット** (GPAW PBE): MoS2 単層 @a=3.16 の IP 5.94 / EA 4.21 eV (K 点ミッドギャップ −5.075 eV)、
  Sb(111) 6BL スラブの仕事関数 4.19 eV (実験 4.55–4.7)。LAK のギャップ開きは PBE ミッドギャップ対称と仮定。
- **損失関数の拡張** (`extended_loss.py`): K 点 VB/CB と Γ 点 VB の曲率相対残差 (W_M=0.5)、Q−K 間隔 (W_Q=10)、
  EIGENVAL 同梱の 12×12 IBZ 19 点メッシュ (W_MESH=1)、絶対整列 (W_AL=2)。境界張り付き変数の範囲拡張、シフト正則化廃止。
- **optm2** (600 試行 TPE、2 ワーカー 1.2 h) → 最良 #434。zoom (±15% 範囲) 磨きは cmaes パッケージ不在で未実施。
- **Sb 第 3 世代** (`optimize_sb3.py`): SOC (ξ=0.57) をループ内に、PBE+SOC パス + 16³ 全 BZ メッシュ (E_F±1.5 eV RMS と
  状態カウント法オーバーラップ) + スラブ E_F 整列を同時フィット。optsb4 (300) → optsb4c (zoom 150)。
- **O 再フィット** (opto3、150 試行、optm2 ベース): 共通シフト再アンカーでは O 2s が 0.36 eV ずれたため。
- **反発**: Mo/S は CCS rep 型 + 力込み (E(a) RMS 114 → 28 meV/cell、a_eq +1.1% → +0.09%)。
  Sb–Sb / S–Sb は GPAW PBE の E(V,u)+異方ひずみ+Sb2S3 (E(V)+ランダム変位) 30 構造で CCS **sw 型・エネルギーのみ** フィット
  (rep 型は E_rep ターゲットが単調減少でなく不可)。**注意: sw 型は MoS2 では緩和で破綻 (a +17%) したので Mo/S には使わない。**
- **SOC 再較正**: Mo 4d ξ = 0.0953 eV (K 分裂 150 meV)、Sb 5p ξ = 0.571 eV (Γ 点多重項スパン 0.950 eV 法。パス RMS 走査法は
  0.20 に落ちるので不採用)。
- **検証**: Sb2S3 (輝安鉱、PBE 緩和構造) バンド、Sb(111) 2BL / 4×4 MoS2 界面、格子緩和テスト。
- 殻別 Hubbard U (ShellResolvedSCC) を skf_v3 に入れる試験 → バンド・V_S とも悪化、不採用。

## 残っている問題・注意
- **有効質量と V_S 準位はトレードオフ**: 質量重み 3 倍 + Mo 4d 指数独立の optm3 (実行中、暫定: m*VB −0.85 / m*CB 0.79 / V_S 0.73)。
  `make_v5.py --out skf_v5m --mos2-study optm3,optm3c --sb-study optsb4c --o-study opto3` で比較セットを組める (O は optm2 ベース)。
- Sb の絶対整列は **PBE 仕事関数 4.19 eV** 基準。実験値 (4.6) に合わせるなら Sb-Sb.skf 2 行目の 5s/5p onsite を
  −0.4 eV (−0.015 Ha) 下げて再フィット/再検証する (1 変数)。
- Sb 反発 (sw 型) は E(V) 走査上は良いが、バルク Sb の全緩和では体積 −5%、菱面体角 59.7° (実験 57.1°) と
  パイエルス歪みを過小評価。コンタクト計算は Sb 側 DFT 構造固定を推奨。Mo–Sb 反発は無し (ゼロ)。
- 力込み CCS フィットは Sb で発散、Mo/S でも E(a) 単独より劣る (ただし緩和構造は最良)。
- DFTB+ の輸送 (libNEGF) 再ビルドは submodule 取得が必要で未実施。スナップショット力データ (RunPod) 未使用。
- MoS2 の低い S-s バンド (−6 eV) は重み 0.2 で放置 (輸送に無関係)。

## 追記 2: 第 2 ラウンド (1) DFTB+U と (2) 反発ターゲット単調性 → skf_v6 (15:30)

**(1) Mo 4d への DFTB+U (FLL) スキャン** (`scan_u_mo.py`, skf_v5m、再フィット無し): V_S 準位は U に対して直線的に浅くなり、
U = 0.08 Ha (2.2 eV) で目標 0.554 eV に一致 (0.734 → 0.694 / 0.650 / 0.600 / 0.545 / 0.482 @ U = 0.02 / 0.04 / 0.06 / 0.08 / 0.10 Ha)。
副作用 (再フィット前): K ギャップ 1.90 → 1.77 eV、VBM(K)−VBM(Γ) +0.03 → +0.14、Q−K 0.29 → 0.40 (U=0.08)。質量はやや軽くなる。
**(2) 反発ターゲット D(a) = E_LAK − E_elec の単調性** (`erep_shape.py`): v3・v5 は単調 (rep 型フィット成功)、v5m は 2.9–3.1 Å で増加
(rep 型失敗) と対応した。損失に W_REP·Σ max(0, ΔD)² (W_REP=100) を追加。

**optm4** (質量重み 1.5、Mo 4d 指数独立、U ∈ [0, 0.12] Ha を最適化、単調性項、600+160 zoom 試行) → **skf_v6**:
- 採用 U = 0.030 Ha (0.81 eV)。単調性 mono = 0 達成 → rep 型 (+力) フィット可: E(a) RMS 56 meV、緩和 a +0.27% / 厚さ −0.26%、
  Sb2S3 内部緩和 RMS 0.11 Å (v5m 0.27)。Sb 反発は再フィット (バルク 22.5 / Sb2S3 28 meV)。
- バンド: loss 0.262、gap 1.850、VBM(K)−VBM(Γ) +0.041、Q−K 0.257、整列 +0.009、質量 −1.00 / +0.90 (v5 並みに戻る)、V_S 0.671 (v5m 0.734、目標 0.554)。
- O (opto5): gap 1.771、O2s 誤差 14 meV、VB RMS 0.35。SOC ξ_Mo(4d) = 0.0885 eV。界面 E_F − CBM = +0.003 eV。
- **DFTB+ 入力に `OrbitalPotential` ブロックが必須** (skf_v6/orbital_potential.hsd)。SKF だけでは v6 の物理は再現されない。

**分かったこと**: 単調な反発ターゲット (物理的に健全な rep 型反発) と軽い有効質量は両立が難しく、optm4 は質量を捨てた。
V_S 重み 4 倍 (optm5) でも種を超えられず、U は 0.03–0.04 Ha に留まる (U を上げるとギャップ・Γ–K 順序が崩れ、
それを再フィットで戻す自由度が無い)。ゲートを緩めて軽質量+単調の試行を種にした optm6 を実行中。

**用途別の推奨**: 純粋 MoS2 の輸送 (質量・谷) → v5m。V_S 欠陥系 → v7 (+U ブロック必須、`skf_v7/orbital_potential.hsd`)。
構造緩和・エネルギー → v6 または v7 の rep 型反発 (v5m の sw 型は MoS2 以外への転移性が弱い)。O_S 系はどれも無準位で、v7 の VB スペクトルが最良。
**残る限界**: 軽い質量 (v5m) と V_S 準位 (+U) と単調反発は同時には満たせない。+U はギャップ・Γ–K 順序と拮抗し、質量を重くする。
